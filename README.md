# 双休购 2.0·公开资料与消费决策工具

一个独立、非官方、无广告返利的公益信息站：按行业检索企业、品牌与代表产品，穿透经营主体、比较证据完整度、寻找同类替代，并在浏览器本地生成个人复核清单。

“双休”不等于所有人固定周六、周日休息。总部、工厂、门店、销售、产研、客服和外包供应商可能采用完全不同的工作制。本项目不对企业作法律定性，也不提供付费排名。

## 当前数据
- 246 条去重后的企业/品牌记录
- 13 个行业分类
- 10 组公开资料来源
- 证据分为 A 公开确认、B 媒体报道、C 汇总候选、作息待核验、风险提示
- 资料研究日期：2026-09-09

网站默认只展示 A/B/C 条目；其中 C 仍是购买前必须复核的候选线索。仅建立了产品关系的记录不会进入默认认购结果。

## 功能
- 搜索品牌、企业、产品或服务
- 按行业和证据层级筛选、排序
- 证据护照：四维、可解释、可复算的公开证据完整度评分
- 主体穿透：产品 → 品牌 → 经营主体 → 作息证据关系链
- 品牌对比：在同一把尺上比较来源、时效、产品和适用范围
- 同类替代：为待核验或风险条目提供同分类的 A/B/C 候选
- 永久品牌链接：将单条记录和原始证据直接分享给其他人
- 查看每条记录的岗位范围、资料摘要与原始来源
- 将 A/B/C 条目加入本地认购清单
- 复制清单或导出 UTF-8 CSV
- 下载包含全部记录、来源和动态证据护照的开放 JSON
- 数据完整性 CI：每次提交自动检查重复记录、失效来源引用、评分越界和替代项跨行业
- 通过 GitHub Issue 补充证据、反证或主体更正
- 纯静态 HTML/CSS/JavaScript，无账号、无分析脚本、无购买返利

## 证据完整度引擎

总分 100 分，只衡量公开证据是否完整，不衡量企业好坏：

- 证据等级 40 分：A/B/C/待核验/风险提示采用公开固定权重；
- 资料新鲜度 20 分：优先选择企业确认/公开通知等最高质量来源，再在同级来源中取最新日期，避免新发布的二手汇总掩盖旧的一手材料；
- 范围清晰度 20 分：识别总部、工厂、门店、部门、岗位和边界提醒；
- 来源可追溯 20 分：依据可访问来源数量计算。

算法位于 insight.js，页面和导出的开放数据使用同一实现。

运行数据校验：
```
npm test
```

## 设计原则

2.0 视觉借鉴小米商城的产品级首屏、强分类入口、大面积留白和单一橙色动作色；未复制小米商标、宣传图、产品图或页面代码。信息密度、证据颜色和功能结构仍服务于本项目自己的核验场景。

首页主视觉 `assets/weekend-hero.webp` 为本项目通过 Codex 内置图像生成能力创作的原创素材：以休闲椅、无品牌包装和两个橙色周末方块表达“把周末还给生活”，画面内不包含第三方商标、文字或水印。

## 数据维护

主要数据位于 `data.js`。新增或更正记录时，请至少提供：
- 企业/品牌名称与准确法人主体；
- 城市、部门、岗位类型与适用时间；
- 具体工作制（固定双休、周休两日排班、大小周、单休、倒班等）；
- 可公开访问的原始来源；
- 品牌、委托方、生产商和门店运营方之间的关系。

完整的资料边界和分级方法见 RESEARCH.md。
