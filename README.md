## 做成手机 APP（网页套壳）

本项目是纯静态网页，可用「一个木函」APP 一键套成 APK：

1. 下载安装「一个木函」（Android）
2. 打开 → 工具箱 → 网页转应用
3. 填入网址：`https://dujeongil-galaxy.github.io/shuangxiugou-guide/`
4. 应用名称和包名自定义即可
5. 生成 APK 安装即可
